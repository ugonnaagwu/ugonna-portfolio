# Ugonna Agwu Portfolio

This is the updated static version of the portfolio using the supplied UA logo, headshot, certificate, navy/gold branding, GitHub and LinkedIn.

## GitHub Pages
Upload the contents of this folder to the root of the `ugonna-portfolio` repository. Keep `index.html` and `styles.css` in the repository root and the `assets` folder beside them. Then use Settings → Pages → Deploy from branch → `main` → `/(root)`.

The site does not require Node.js or VS Code to host.
